Autonomous Warehouse Simulator (OpenSiv3D)Siv3Dを使用した、グリッドベースの自律移動ロボットシミュレーターです。
複数のロボットが衝突を回避しながら、指定されたステーションへ荷物を運搬するアルゴリズムをシミュレートし、効率性を分析できます。
🌟 主な機能衝突回避システム: グリッド予約方式により、ロボット同士の衝突や重なりを防止します。ヒートマップ可視化: ロボットがスタック（渋滞）しやすい場所をリアルタイムに色付けし、レイアウトの問題点を特定できます。
インタラクティブ・エディタ: 実行中にマウス操作でステーション（荷降ろし場）を自由に配置・削除できます。
統計分析: 総処理数や、荷物を届けるまでに必要な平均周回数などのパフォーマンス指標を表示します。シミュレーション制御: ロボットの台数調整や、最大8倍までの倍速シミュレーションが可能です。
🛠 アルゴリズムの概要移動 (Flow Field): ロボットは基本的に右方向へ移動し、右端に到達すると左端に戻るループ構造を持っています。
予約 (Reservation): 移動する前に、移動先のセルが空いているか確認し、IDを登録することで他ロボットの進入を防ぎます。動的ルート変更: 自分の持っている荷物（色）と同じ色のステーションが隣接している場合、通常のフローを優先してステーションへ向かいます。🚀 実行方法前提条件Windows / macOS / LinuxSiv3D (OpenSiv3D) がインストールされている開発環境ビルドと実行Siv3D のプロジェクトを作成します。
Main.cpp にこのリポジトリのコードをコピー＆ペーストします。
ビルドして実行（F5キーなど）してください。
🎮 操作方法操作アクションマウス左クリック選択中の色のステーションを配置マウス右クリックステーションを削除Slider (Count)シミュレーション上のロボット台数を変更RadioButtons配置するステーションの色を選択Speed Buttonsシミュレーション速度（1x / 8x）の切り替え📊 統計情報Total Processed: 荷物を正常に届けた累計回数。Avg Laps to Deliver: 1つの荷物を届けるために、ロボットが平均して何周したか（低いほど効率的）。
